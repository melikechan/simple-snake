# Simple Snake

> [!WARNING]
> This project is **still WIP** and **far from being playable.**

You probably know the [_snake game_](<https://en.wikipedia.org/wiki/Snake_(1998_video_game)>) in Nokia phones.

**Simple Snake** is a version of the _snake game_ including some game modifiers, written in Python, and runs on your **terminal**.

## Running the Game

This game requires **Python 3.14+**. _(will be tested on older versions)_

1. Clone the repository:

```sh
git clone https://github.com/melikechan/simple-snake.git
cd simple-snake
```

2. Install dependencies:

```sh
pip install -r pyproject.toml
```

3. Run the game:

```sh
python main.py
```

## Gameplay

### Controls

| Keys  |   Action   |
| :---: | :--------: |
| ↑ / W |  Move up   |
| ↓ / S | Move down  |
| ← / A | Move left  |
| → / D | Move right |
|   p   |   Pause    |
|   q   |    Quit    |
